## Board Topology (Left-to-Right Flow)

Structure the Miro board into 5 distinct Frames arranged linearly from left to right.
Connect them with visual directional arrows so participants always know where to look.

+------------------+   +------------------+   +------------------+   +------------------+   +------------------+
|     FRAME 1      |   |     FRAME 2      |   |     FRAME 3      |   |     FRAME 4      |   |     FRAME 5      |
|  Context & Metric|-->| Fishbone Brain-  |-->| Root Cause Deep- |-->| Solution Matrix  |-->| Improvement      |
|  Problem Statement|   | storming Board   |   | Dive & Isolation |   | (Impact/Effort)  |   | Backlog Stories  |
+------------------+   +------------------+   +------------------+   +------------------+   +------------------+
## Frame-by-Frame Visual Setup

**Frame 1**: Context & Problem Statement (15 min)

**Visual Anchor**: Big bold header banner at the top (#1E293B dark charcoal background).

**Left Box (Metrics Widget)**: Sticky notes or text blocks summarizing the team's Predictability Score (80–100%) and key operational metrics from the PI.

Center Box (Problem Statement Focus): A prominent light-red frame (#FEE2E2) titled "Agreed Problem Statement".

Miro Tip: Lock this box once agreed upon so participants can refer back to it without accidentally moving it.

**Frame 2**: Fishbone (Ishikawa) Diagram (30 min)
Background Canvas: A pre-drawn central spine pointing right toward the Problem Statement.

**6 Category Ribs**: Use color-coded text shapes for the category headers:

🟨 Process (Yellow sticky area)

🟦 Tools & Infrastructure (Blue sticky area)

🟩 Data & Governance (Green sticky area)

🟧 People & Skills (Orange sticky area)

🟪 External Dependencies (Purple sticky area)

⬜ Environment (Gray sticky area)

Sticky Note Stacks: Place infinite pre-made stacks of sticky notes near each category rib for quick dragging during silent brainstorming.

**Frame 3**: Primary Root Cause Isolation Zone (15–20 min)
Divide Frame 3 into two interactive sub-zones side by side:

Zone A: The 5 Whys Ladder
Layout: A vertical sequence of 5 descending card containers (#F1F5F9 light slate) linked with down arrows (↓).

Interactive Element: As the facilitator types the team's responses, visually highlight the 5th container in gold (#FEF08A) as the Root Cause Winner.

Zone B: Impact vs. Control Grid
Layout: A large 2×2 grid matrix with two clear axes:

Y-Axis: Systemic Impact (Low → High)

X-Axis: Team Control / Influence (Low → High)

**4 Quadrants**:

Top-Right: Focus Zone (Bright Green background #DCFCE7)

Top-Left: Escalation Zone / RTE (Bright Amber background #FEF3C7)

Bottom-Left: Out of Scope (Gray background #F3F4F6)

Bottom-Right: Low Priority (Light Gray background)

**Frame 4**: Solution Brainstorming Matrix (20 min)
Layout: A 2×2 Impact vs. Effort prioritization board.

Quadrant 1 (Top-Left): Quick Wins (High Impact / Low Effort) → Light Green

Quadrant 2 (Top-Right): Major Enablers (High Impact / High Effort) → Light Blue

Quadrant 3 (Bottom-Left): Low Priority (Low Impact / Low Effort) → Light Gray

Quadrant 4 (Bottom-Right): Avoid (Low Impact / High Effort) → Light Red

**Frame 5**: Actionable Improvement Backlog (15 min)
Layout: Structured Kanban card containers matching your Jira/Azure DevOps story template.

Card Fields:

📌 Story Title / Summary

🎯 Problem Addressed (Linked to Frame 3 Root Cause)

✅ Acceptance Criteria (Checklist widget)

👤 Owner & Target Sprint

🎨 Color-Coding & Sticky Note Palette Standard
To keep visual cognitive load low for remote participants, establish a clear color key on the board:

Sticky Color	Meaning / Function
🟨 Yellow	General observations / Process friction
🟥 Red / Pink	Severe blockers / System failures / Defects
🟦 Blue	Infrastructure, CI/CD, or Tooling issues
🟩 Green	Proposed solutions / Action items
🟪 Purple	Upstream/Downstream external dependencies

## ⚡ 5 Essential Miro Facilitation Tips for Remote Sessions
Lock All Background Artifacts: Lock (Cmd/Ctrl + L) all background frames, lines, headers, and templates so participants only move sticky notes.

Use Miro Built-in Timers: Set a visible 5-minute timer on screen for silent sticky-note writing during brainstorming steps.

Use Voting Tool with Constraints: Use Miro's native Voting Plugin. Set parameters to 3 votes per person, restricted strictly to sticky notes inside Frame 2.

Bring Everyone to Your Focus (Bring Everyone to Me): During stage transitions, use Miro’s facilitator feature to pull all remote screen views to your active Frame.

Pre-populate Sticky Note Bundles: Place small groups of empty sticky notes near each section before the meeting starts so participants don't waste time creating new shapes.
